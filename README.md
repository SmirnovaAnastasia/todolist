# Todolist

## Проект todolist имеет три категории: список дня, невыполненные дела и архив.

<ins>Список дня</ins> - выводит все дела на сегодняшнюю дату, в случае отсутствия создает его. В этом блоке можно записывать дела да день, изменять их статус и актуальность.

<ins>Невыполненные дела</ins> - выводит все невыполненные дела за все дату, представленные в базе.

<ins>Архив</ins> - выводит все дела за даты, кроме нынешней.

# Версии
## На данным момент в проекте есть три версии, они имеют небольшие отличия в функционале.

<ins>Версия 1</ins> - базовая консольная версия, данные лежат в json файле.
